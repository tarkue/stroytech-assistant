# Соответствие варианту 2025_Б16

Исходное задание: `Задания_сутденты_ИДЗ_СИИ_2026_осень_часть1_01.docx`, раздел «2025_Б16. Строй.техника», Петров Виктор / Евгений Смирнов. Исходники использовались только для чтения.

| Требование | Представление в прототипе |
|---|---|
| Работы, объект и погода → варианты техники, оценка заказа | Заказ с перечислениями, трехзначными условиями и числами; ядро рекомендаций; таблица и стоимость |
| Скала при земляных/бурильных работах: допоборудование | Продукционные правила требований и учебных надбавок |
| Воды, болото, мягкий грунт вместе с погодой: доступ | Факты и правила риска доступа, промежуточные факты |
| ЛЭП, масса, грузоподъемность, вылет, угол | Поля заказа, учебная грузовая таблица, проверка полноты и ограничений; назначение cargo/people разделяет краны/манипулятор и автовышку |
| Мягкий грунт и препятствия: риск опрокидывания | Совместные условия продукционных правил |
| Тяжелые грузовики и бетономешалки: дождь, слякоть, мягкий грунт | Условия по погоде/грунту и признаку тяжелой техники |
| Самостоятельные дополнительные условия | Узкий подъезд, ночь и освещение |
| Извлечение правил нейросетью | Локальная Ollama, структурированные кандидаты без выполнения кода |
| Сущности, намерение, причинная связь | `entities`, `intent`, `evidence`, `conditions`, `effects` кандидата |
| Противоречия / расхождения фактов | Валидация и проверка несовместимых фактов, экспертное утверждение |
| Эксперимент с очередностью обработки | Два режима `filter_first` и `extract_first`; результаты и протокол следует сравнивать на одинаковых текстах |

Слои БЗ, рабочей памяти, решателя, объяснения и приобретения знаний взяты из курса. Обратный вывод, полноценный фреймовый движок и промышленная оптимизация парка не обязательны для Б16 и здесь не заявляются.

Источники курса перечислены ниже относительно каталога материалов `task SII labs`. Исходные документы не включены в репозиторий и использовались только для чтения.

- `task 9/Л3_СИИ_статич_динамич_ЭС_2026.pdf` — состав статической экспертной системы.
- `task SII 4/task SII/Л2_Представление_знаний_Фреймы1_2026.pdf` — представление объектов и слотов; словарь заказа/техники служит структурированным представлением, не полноценной фреймовой системой.
- `task SII 4/task SII/прошлая работа.docx` — материал о прямом и обратном выводе; в проекте используется прямой вывод.
- `task SII 4/Смирнов_ЕС_Продукционные_правила_БД.docx` — правила и конфликты.
- `task SII 4/task SII 3/Л2_Представление_знаний_Вывод_на_Фреймах.pdf` — альтернативные представления/вывод.

План пользователя: `Untitled.rtf` — предоставленный RTF-план коллеги; материал не изменялся.
